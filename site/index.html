RDS and Aurora Extended Support calculator

Once a PostgreSQL or MySQL major version leaves standard support, AWS bills Extended Support per vCPU-hour on every node that runs it: the primary, any Multi-AZ standby and every read replica. Enter your databases to see what that costs and when the price goes up. Dates are from the AWS release calendars; prices are estimates. What you enter stays in your browser.

Scan every account and region with eol-scan

eol-scan is a free, open-source command-line tool that does this for your real fleet. It lists every RDS and Aurora database on a version past standard support, adds up the Extended Support charge per database and flags upgrade blockers. It only reads, runs on your machine with your own AWS credentials, and sends nothing anywhere.

pip install git+https://github.com/__REPO__.git
eol-scan --all-regions

Source code and documentation on GitHub

Dates come from the AWS release calendars. Years 1–2 and year 3+ rates by region come from a third-party summary of the AWS price list; Europe (Frankfurt) was checked against the official AWS Price List in November 2026. Other regions may have changed, so confirm on the AWS pricing page before you quote a number. Aurora Serverless (billed per ACU-hour) and Reserved Instance discounts are not modelled.
